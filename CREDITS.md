## Made by the team (not third party)

- The two player sprites (`assets/chars/circle_grey.png`, `circle_cyan.png`) were drawn and chosen by the team, then cropped and resized for the game.
- The Orpheus and Eurydice story, the level and puzzle design, the characters and all dialogue were decided by the team.

## AI tools used

AI was used heavily and openly. The core design and direction (story, characters, the five-strip comic page, ink plague mechanic, co-op notes, twisted dialogue idea) are the team's own.

- **Claude Code (Anthropic, Claude Sonnet model)** wrote the game code in `scripts/` and `tools/`, the level data in `scripts/levels.gd`, the in-game dialogue text and narrator lines, the in-game drawing of panels, plates, gates and ink, and this README and credits file, all in the repo's commit history during the jam.
- **Sound effects and music** were generated by a Python script written by Claude Code (`tools/gen_audio.py`, Karplus-Strong string synthesis). No audio samples were used.
- **Claude (Anthropic)** also helped plan the project, write art prompts and set up Godot during the jam.
- All comic art (backgrounds, story characters, page thumbnails, title image) is supplied by the team as image files in `assets/`. The tool used to make each image will be listed here when the files are added.
